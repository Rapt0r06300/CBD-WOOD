# CRO-138 — comparaison partageable

Les quatre catalogues permettent de sélectionner deux ou trois références puis d'ouvrir une comparaison accessible. Le tableau reprend uniquement les libellés déjà visibles sur les cartes : nom, univers, profil affiché, disponibilité et prix affiché. Toute donnée absente reste « à confirmer ».

L'état public utilise uniquement `compare=id1,id2,id3` et peut être copié sans appel serveur. Le bouton est désactivé tant que deux références ne sont pas sélectionnées, et la limite de trois évite un tableau illisible sur mobile.
