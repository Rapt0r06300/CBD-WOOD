# CRO-051 — Repère d’échelle réaliste

Statut : **préparé localement ; `BLOCKED-EXTERNAL` pour la clôture**.

## Ce qui est livré dans la démo

Les fiches fleurs réservent un bloc `data-scale-reference-state="pending"`
pour un repère physique neutre. Le bloc indique clairement qu’aucune mesure
n’est publiée et que la référence doit être ajoutée avec une photo autorisée.
Il fonctionne sur desktop et mobile sans modifier le prix, le grammage ou le
CTA.

## Ce qui manque pour valider la tâche

Une référence physique réelle, une photo authentique et l’accord de la
propriétaire sont nécessaires pour établir une mesure authentique. Aucun objet,
ratio ou volume n’est inventé dans cette préparation.
