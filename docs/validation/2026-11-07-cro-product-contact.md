# CRO-149 — question liée à une fiche

Chaque fiche peut proposer un lien vers le formulaire de démonstration avec le seul nom public de la référence dans le paramètre `produit`. Le formulaire préremplit localement une phrase courte et reste désactivé : aucun envoi, compte ou identifiant visiteur n'est créé.

Le lien est présent sur les fiches fleurs et les fiches génériques, et la préparation publique inclut `wood-contact-prefill.js` dans les deux variantes base/démo selon le paquet construit.
