# TXW-087 — Reflow 200 % et 400 %

Date : 7 novembre 2026  
Périmètre : site de démonstration WOOD uniquement.  
Recette : Chromium local, commit de référence `b6a12e2`.

## Méthode

La recette utilise le viewport CSS équivalent à un zoom de page :

- 200 % : `720 × 900` CSS pour une référence desktop `1440 × 900` ;
- 400 % : `360 × 900` CSS, ce qui force le repli mobile.

Les routes testées sont l'accueil et `rendez-vous.html`. Les captures sont
`output/playwright/txw087-home-2x.png`, `txw087-home-4x.png`,
`txw087-visit-2x.png` et `txw087-visit-4x.png`.

## Résultats

| Route | Zoom | viewport CSS | scrollWidth | actions rendues |
|---|---:|---:|---:|---:|
| Accueil | 200 % | 720 | 720 | 70 |
| Rendez-vous | 200 % | 720 | 720 | 24 |
| Accueil | 400 % | 360 | 360 | 70 |
| Rendez-vous | 400 % | 360 | 360 | 24 |

Les titres, menus, boutons, cartes, tableaux présents et footer restent dans
le flux ; aucun débordement horizontal du document n'est observé. Les accents
graphiques peuvent dépasser leur boîte d'ancrage interne, mais ne modifient pas
le `scrollWidth` et ne recouvrent pas les actions critiques.

## Limite

Cette preuve est une recette Chromium locale de reflow, pas une certification
du zoom natif Safari iOS/macOS, du Dynamic Type ou d'un appareil physique.
Ces contrôles restent des validations externes et ne sont pas transformés en
résultat local par cette tâche.
