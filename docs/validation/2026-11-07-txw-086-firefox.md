# TXW-086 — Contrôle Firefox desktop

Date : 7 novembre 2026
Périmètre : site de démonstration WOOD uniquement.

## Recette

Navigateur : Firefox local via Playwright CLI.
Viewport : `1 440 × 900` CSS px.
Serveur : paquet local de la branche de démonstration.

| Route | Contrôle | Résultat |
| --- | --- | --- |
| `fleurs.html` | grille, 13 cartes, images, largeur document | 13 cartes, 0 image en échec, `scrollWidth = 1 440` |
| `fleur.html?produit=fleurs-nimbus-3000` | galerie, pictogrammes, boutons, transition de fiche | galerie présente, 16 liens/boutons, 0 image en échec, `scrollWidth = 1 440` |
| `contact.html` | formulaire, champs, actions | 1 formulaire, 7 champs, 7 boutons actifs, `scrollWidth = 1 440` |
| accueil | état social en attente et stabilité du shell | Instagram non relié tant que le compte n'est pas confirmé |

Les captures Firefox sont conservées localement dans `output/playwright/` :

- `txw086-firefox-fleurs-1440.png`
- `txw086-firefox-detail-1440.png`
- `txw086-firefox-contact-1440.png`

La console Firefox n'a remonté aucune erreur ni avertissement sur la recette.
Les contrôles Chromium précédents couvrent le même contrat de grille,
d'images, de transitions et de formulaire ; aucune différence bloquante n'a
été observée sur ces routes.

## Limite

Cette preuve couvre Firefox desktop local. Elle ne remplace pas Safari iOS,
Chrome Android, un appareil physique, un lecteur d'écran ou le clavier virtuel.

Preuve automatisée : `test/txw-086-firefox.test.mjs`.
